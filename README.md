# 돼지우리 당직일지

브라우저에서 바로 실행하는 축사 체험 게임입니다. `index.html`을 열어 플레이할 수 있습니다.

- WASD 또는 방향키로 이동하고 E로 가까운 대상과 상호작용합니다.
- 모바일에서는 화면 오른쪽의 방향 버튼과 E 버튼을 사용합니다.
- 사료는 계속 줄어듭니다. 바닥나면 돼지들이 울고 평화 지수가 떨어집니다.
- 싸움은 작대기로 바닥을 쳐서 해산합니다.
- 건강 관리가 필요한 돼지는 진료실로 보냅니다.
- 도전하는 돼지는 데리고 주차장까지 걸어가 포터에 태워 새 우리로 보냅니다.
- R 키로 처음부터 다시 시작합니다.

GitHub Pages로 공개하려면 저장소의 **Settings → Pages → Build and deployment → Deploy from a branch**에서 `main` / `/ (root)`를 선택하세요. 공개 주소는 `https://anjunhui007-dev.github.io/pig_house/`입니다.

외부 게임 엔진 없이 Canvas와 JavaScript로 구현했습니다. 글꼴만 Google Fonts를 사용하며 연결이 없어도 기본 글꼴로 실행됩니다.
