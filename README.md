# 돼지우리 당직일지

브라우저에서 바로 실행하는 축사 체험 게임입니다. `index.html`을 열어 플레이할 수 있습니다.

- WASD 또는 방향키로 이동하고 E로 가까운 대상과 상호작용합니다. Q로 작대기를 휘두릅니다.
- 모바일에서는 화면 오른쪽의 방향 버튼과 E 버튼을 사용합니다.
- 사료는 돼지가 먹이통 가까이 있을 때만, 근처 돼지 수에 따라 줄어듭니다. 오른쪽 창고에서 최대 4포대를 들 수 있고, 포대 하나마다 이동 속도가 낮아집니다. 먹이통 하나에 포대 하나를 사용합니다.
- 싸움에는 만화풍 케첩이 튑니다. Q로 작대기를 허공에 휘두르면 주변 모든 돼지가 ‘끼익!’ 하며 플레이어에게서 멀어지고 싸움도 해산합니다. 싸움은 10초 안에 말려야 하며, 늦으면 한 마리가 영구 행동 불가 상태가 됩니다. 가까이에서 E로 들어 올려 왼쪽 냉동창고에 옮기고 E로 냉찜질을 시작합니다. 돼지는 작대기에 맞지 않습니다. 가까운 돼지에게 E를 누르면 기선제압합니다.
- 주기적으로 새끼 돼지가 태어나며 15% 확률로 특별 돌봄이 필요한 새끼가 나옵니다. 가까이에서 Q로 작대기를 사용하는 짧은 비현실적 연출이 진행됩니다. 아픈 돼지도 들어서 왼쪽 냉동창고로 옮겨 냉찜질시킵니다.
- 도전하는 돼지는 데리고 주차장 포터 앞으로 갑니다. 주차장에서 대결이 자동으로 시작되며 플레이어가 반드시 이깁니다. 승리 후 E를 눌러 포터로 편히 보냅니다.
- R 키로 처음부터 다시 시작합니다.

GitHub Pages로 공개하려면 저장소의 **Settings → Pages → Build and deployment → Deploy from a branch**에서 `main` / `/ (root)`를 선택하세요. 공개 주소는 `https://anjunhui007-dev.github.io/pig_house/`입니다.

외부 게임 엔진 없이 Canvas와 JavaScript로 구현했습니다. 글꼴만 Google Fonts를 사용하며 연결이 없어도 기본 글꼴로 실행됩니다.
